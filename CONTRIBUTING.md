# Contributing

Исправления данных, новые проверки и улучшения коллектора приветствуются.

## Перед pull request

```powershell
npm ci
npm test
pwsh -NoProfile -File .\test\powershell-wrapper.test.ps1
npm run build:api
npm run validate:api
```

Не добавляйте в Git содержимое `out/`, сетевые логи и кэш. Изменение правила отбора должно включать тест, а исправление данных — ссылку на публичное доказательство.

## Изменение формата

- Добавление необязательных полей допустимо в текущей версии schema.
- Удаление, переименование или изменение смысла поля требует новой major-версии schema/API.
- Versioned API-файлы опубликованного выпуска не изменяются.

Перед выпуском новой версии обновите `api/releases.json`, проверьте рассчитанные SHA-256 и убедитесь, что delta построена относительно предыдущего выпуска.
